İonenSpiegel GA4 düzeltmesi

1. Eski ga4.js dosyasını GitHub reposunun ana klasöründen kaldır/değiştir.
2. Bu ZIP içindeki ga4.js dosyasını ana klasöre yükle.
3. index.html içindeki <script src="./ga4.js?v=64" defer></script> satırına dokunma.
4. GitHub Pages güncellendikten sonra siteyi aç.
5. Google Analytics > Gerçek Zamanlı bölümünden kontrol et.
